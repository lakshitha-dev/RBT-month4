# Lighthouse report

Generated by [`scripts/lighthouse.mjs`](../../scripts/lighthouse.mjs) against the **production build**:

```bash
npm run build
npm run lighthouse          # needs a local Chrome/Edge (or set CHROME_PATH)
```

The script:

1. Serves `dist/` with `vite preview`.
2. Uses puppeteer to seed a signed-in session, so protected pages (Dashboard, Users) can be audited, not just the login page.
3. Runs Lighthouse with the **mobile** preset (simulated Slow 4G, 4× CPU slowdown) and the **desktop** preset.
4. Runs each page/profile **3 times** and keeps the **median run** by performance score. This follows Lighthouse CI practice, because single runs vary by several points. Every run's score is listed in the summary, so the spread stays visible.
5. Writes `<page>-<profile>.html|json`, `summary.md` and the combined **`lakshitha-month4-lighthouse.pdf`** (a summary cover page followed by every full report).

Results: **[summary.md](summary.md)**

Quick iteration: `LH_PAGES=dashboard LH_PROFILES=mobile LH_RUNS=1 npm run lighthouse` (skips the PDF).
